Sync podešavanja

Klik na Sync to GitHub može da:

  1. Direktan commit — preko GitHub Actions workflow-a (treba ti token).
  2. Skida fajl (ako nema tokena) — pa ručno pokreneš _sync-must-see.sh.

Za direktan commit: napravi fine-grained PAT sa skopovima:

  1. Repository access: Only select repositories → izaberi beldocs-private
  2. Permissions: Contents: Read and write i Metadata: Read
  3. Kopiraj generisani github_pat_… token i zalepi ovde:

Token se čuva u localStorage tvog browsera, ne šalje se nigde osim na api.github.com.
